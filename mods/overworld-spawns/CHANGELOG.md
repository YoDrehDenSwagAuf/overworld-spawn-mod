# Changelog

## 1.0.0

### Added

- Data-driven wild Pokémon spawns on grass tiles using each map's encounter table.
- Step/touch collision that starts the exact wild battle for that species and level.
- Dual-mode rendering: vanilla 2D SpriteRenderer cards and VoxelScene billboards when Dramatic Shape is active.
- Options for max spawns, spawn interval, random-encounter suppression, and visual tuck opacity.
